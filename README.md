# 设备连接监控 DeviceWatch

实时监控 Windows 上所有设备的**接入 / 断开 / 故障**，同时采集硬件传感器（温度、功耗、频率、硬盘健康）。
断联立刻弹窗提醒，不用一直盯着。

![监测面板](docs/screenshot.jpg)

## 快速开始

双击 **`设备连接监控.exe`**。

会启动监控、右下角出现托盘图标、自动打开浏览器面板。不需要安装任何东西。

## 能监控什么

**设备接入 / 断开**

- 每次接入和断开都记录，弹窗 + 提示音 + 写进 `logs\events.csv`
- 同一物理设备的多个子接口合并成一条通知（拔一次鼠标只弹一条）
- 3 台以上设备同时掉 → 判定为集线器复位或供电不足
- 系统日志里的硬件错误（磁盘重置、控制器错误）一并记录

**硬件传感器**

| 部件 | 监控内容 |
|---|---|
| CPU | 温度、占用、各 CCD 温度、实时频率、封装功耗 |
| 内存 | 占用、每根内存条温度 |
| GPU | 温度、核心热点、显存结温、占用、功耗、显存用量 |
| 硬盘 | 每块物理盘的温度 / 寿命 / 通电时长 / 分区读写速率 |
| 网络 | 实时收发速率、适配器状态、外网连通性 |
| 其它 | 电压、电池、开机时长 |

全部显示在一个本地网页上：`http://127.0.0.1:8787`

## 网页面板

- **监测范围**：外设 / 硬件 / 外设+硬件，随时切换
- **所有设置都在网页上改**，不用编辑配置文件
- 卡片可拖动排序、调整宽度、隐藏
- **「工具」卡片**：生成设备清单、打开日志文件夹、装/卸开机自启

## exe 命令

| 命令 | 作用 |
|---|---|
| `设备连接监控.exe` | 启动 + 打开网页 |
| `设备连接监控.exe silent` | 启动但不打开网页（开机自启用的就是这个） |
| `设备连接监控.exe stop` | 停止监控 |
| `设备连接监控.exe web` | 只打开网页 |
| `设备连接监控.exe log` | 打开日志文件夹 |
| `设备连接监控.exe autostart` | 安装开机自启（开机不弹提示） |
| `设备连接监控.exe noautostart` | 取消开机自启 |
| `设备连接监控.exe debug` | 带控制台窗口启动，排查问题用 |
| `设备连接监控.exe noelevate` | 不提权启动（读不到内存温度 / CPU 功耗） |
| `设备连接监控.exe inventory` | 生成设备清单 |

## 找出到底是什么东西断联

**1. 看日志**

`logs\DeviceWatch-日期.log`。断联记录后面紧跟着系统日志的硬件错误，对起来看基本能确定是线材、接口、供电还是驱动的问题：

```
21:03:11.482  [断联] USB 输入设备  <USB\VID_046D&PID_C534\...>（本次已连接 2.1 小时）
21:03:12.900  [接入] USB 输入设备  <USB\VID_046D&PID_C534\...>
21:05:40.118  [系统日志/存储控制器] 错误 (storahci) ID=129  重置了设备 \Device\RaidPort0
21:07:02.331  [网卡] 以太网 变为 Disconnected  0 bps
```

**2. 看断联排行**

网页上的「断联排行」按设备统计断联次数，次数最多的最可疑。

**3. 看设备清单**

运行 `设备连接监控.exe inventory`，读出每个设备**自己上报的真实型号**，比设备管理器里的「USB 输入设备」有用得多。

## 常见问题

**双击后什么都没发生？**
等几秒，首次启动要初始化硬件采集（约 4 秒）。还是没有就运行 `设备连接监控.exe debug`，会开窗口显示详细报错。

**杀毒软件报警？**
程序以管理员身份运行，并加载一个开源的签名驱动（LibreHardwareMonitor，MPL-2.0）。容易被杀软盯上，加进信任区即可。

**没有内存温度 / CPU 功耗？**
这两项需要管理员权限。检查 UAC 是否被拒绝。

**网页连不上？**
监控没在运行。双击 `设备连接监控.exe`。

**想省点 CPU？**
网页 →「设置」→「采集」，把各项采集间隔调大。设备插拔检测走独立快速路径，不受影响。

**只想盯外设，不要硬件？**
网页工具栏点「外设」，硬件采样会完全停掉。

**端口冲突？**
网页「设置」里改 WebPort。

## 运行开销

| 项目 | 数值 |
|---|---|
| CPU | 约 0.27%（整机） |
| 内存 | 约 200 MB |
| 启动 | 约 4 秒 |
| 插拔检测延迟 | 约 600 毫秒 |

内存的大头是 PowerShell 运行时本身（约 77 MB）和脚本执行开销，这是用 PowerShell 实现的固有成本。

想再省：

- 网页工具栏切到 **「外设」**：不加载硬件子系统和低层传感器，内存降到约 **148 MB**
- 网页「设置」里关掉 **托盘图标**：再省约 18 MB

## 系统要求

Windows 10 / 11 **x64**，PowerShell 5.1 和 .NET Framework 4.7.2（系统自带）。

不需要安装任何运行时或依赖。整个文件夹拷走就能用。
